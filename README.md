# Minecraft 3DS Store Demo

A standalone browse-only demo of the original Minecraft: New Nintendo 3DS Edition store for version  1.9.19.

You can not actually buy or activate packs from here. This is strictly for preservation purposes.

## Install

1. Install the USA game and its v9408 update.
2. Enable **game patching** in Luma3DS.
3. Copy the ZIP's `luma` folder to the SD card root.
4. Open the game and select **Store**.
